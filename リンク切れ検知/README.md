# 企業特集の求人リンク切れ

手順の全文は [運用マニュアル](運用マニュアル.md)。ここには、今動いていることと、まだ動いていないことだけを書く。

対象は [【RDS・RAG特集記事】進捗管理シート](https://docs.google.com/spreadsheets/d/1QR_zn768KnvHG1NfKGvIphvMeNUgA1ZN6i-XTculiBw)。触るタブは「RDSサイト_求人リンク切れ」「RAGサイト_求人リンク切れ」と、手順文だけの「求人リンク切れの運用」。

## 今動いていること

- 毎週月曜、日本時間 9:00〜10:00 のあいだに、スプレッドシート紐づきの Apps Script `weeklyJobLinkCheck` が動く。公開ページを見て、新しく切れた求人だけを末尾へ追記する。
- 同じ走査で、M列「掲載求人有無」を更新する。
- ソースの正は `apps-script/WeeklyLinkCheck.gs`。プロジェクト名は「求人リンク切れ週次チェック」。
- 手元で同じ収集をするときは、このディレクトリで `python3 check_rds_links.py` と `python3 check_rag_links.py`。結果は `out/`。シートは更新しない。

## まだ動いていないこと

- 切れている求人カセットを WordPress から外す処理。月曜のジョブは削除しない。
- 記事の非公開・削除、代替求人の追加。
- O列「方針」、P列「追加求人URL」、Q列「PD対応」の自動入力。人が書く。週次処理はこれらの列を上書きしない。

判定の詳細、列の担当、パスワードの入れ替え、将来削除を付けるときのブロック構造は運用マニュアルに書いてある。
